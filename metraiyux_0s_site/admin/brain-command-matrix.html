Command lifecycle

  1. Admin sends instruction in the chat window.
  2. Main Automation Brain classifies intent.
  3. Primary cabinet brain receives the operating task.
  4. Secondary brain checks risk, QA, compliance, or operational fit.
  5. Approval gate decides whether this stays internal or can move externally.
  6. Worker records the command, task, approval, social draft, and audit receipt.
