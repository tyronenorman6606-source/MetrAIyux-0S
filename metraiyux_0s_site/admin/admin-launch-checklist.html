Admin Automation Launch Checklist

Use this before claiming the autonomous business system is live.

Deployment checklist

  • Deploy the static site or Worker static assets.
  • Create Cloudflare D1 database for admin automation.
  • Run migration 0001_admin_automation_schema.sql.
  • Create KV namespace for fast chat/task lookups.
  • Create Queue for async social/content dispatch tasks.
  • Set ADMIN_TOKEN as a Worker secret.
  • Optional: set SOCIAL_DISPATCH_WEBHOOK for posting connector.
  • Open /admin/automation-brain.html and save Worker endpoint.
  • Paste token into the admin session field.
  • Run status, chat, task, approval, and social draft smoke tests.
  • Keep public publishing approval-gated until provider connector proves successful.

Smoke commands

curl https://YOUR-WORKER.workers.dev/api/admin/status
curl -X POST https://YOUR-WORKER.workers.dev/api/admin/brain/chat \\
  -H 'content-type: application/json' \\
  -H 'authorization: Bearer YOUR_ADMIN_TOKEN' \\
  -d '{"message":"Draft 3 staffing social posts and queue for approval."}'
