Admin Tutorial · Lesson 08

Cloudflare Worker Setup

Deploy the admin automation Worker when you need persistence, shared operation, and current proof surfaces.

010203040506070809101112131415

Operating steps

  1. Install Wrangler.
  2. Create D1, KV, Queue, and SITE_EVENTS_KV resources.
  3. Set ADMIN_TOKEN and RESEND_API_KEY as Worker secrets.
  4. Run npm run 0s:build:proof so changelog and SkyeVault autosync proof files are current before deploy.
  5. Deploy with npm run 0s:worker:deploy; the deploy script runs the proof publisher again before Wrangler.
  6. Save the Worker origin inside the admin chat window.
  7. Open SkyeVault Command Center to review /api/skyevault/autosync-notify-settings and the generated autosync proof page.
