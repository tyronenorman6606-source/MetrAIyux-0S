Admin Login and Operating Modes

Understand local mode, Worker mode, admin token sessions, and why live posting requires deployed connectors.

Operating steps

  1. Open the Admin Automation OS from /admin/index.html.
  2. Use browser-local mode for demonstrations, training, and offline testing.
  3. Use Cloudflare Worker mode when you need shared ledgers, persistent chat, task queues, and provider dispatch.
  4. Store the Worker endpoint in the admin screen and paste the ADMIN_TOKEN into the session token field.
  5. Never place secret tokens in public HTML, static JSON, or Git-tracked files.
