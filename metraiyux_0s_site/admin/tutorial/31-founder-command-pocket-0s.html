Lesson 31

Founder Command Pocket 0S

Founder Command is the owner phone cockpit: shared gate first, real apps underneath, founder-only controls on top.

1. Open the Core Apps tab

Use /founder-command/?view=core to launch SkyeMail, FS27/SkyGate, SkyePay, SkyeNet, Business Card Factory, ConnectLog cards, Client App Factory, Valley CRM, and other core apps.

2. Use the SkyeMail mini console

The compact SkyeMail card syncs mailbox status, unread count, aliases, key state, and recent messages through the 0S Worker. Full compose and inbox actions open the real SkyeMail app.

3. Edit the dock

Add or change app shortcuts from the Core Apps form. Keep app logic in the real mounted app; Founder Command should launch or preview it, not fork it.

4. Keep auth canonical

Every mounted app still belongs to FS27/SkyGate/Free99. Founder Command does not create a second owner password or store client plaintext passwords.
