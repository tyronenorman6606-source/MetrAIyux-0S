Primary name

MetrAIyux 0S is the public platform name. Use it on the homepage, tutorials, docs, valuation pages, SaaS pages, Cloudflare deployment notes, and customer-facing explanations.

Layer names

Owner/Admin OS

The protected operator side. This includes the Main Automation Brain, production connectors, approval inbox, proof vault, and owner credentials.

Customer SaaS Layer

The tenant-scoped customer side. Customers can sign up, onboard, create a workspace, select services, and run their own isolated commands.

Main Automation Brain

The owner-side orchestrator that can coordinate tasks, social drafts, approval gates, proof receipts, and external connectors after deployment.

0meg4kAI

The 16th brain. It handles security review, QA, tenant isolation, privilege-escalation checks, approval-risk scoring, and system audits.

13-Cabinet Model

The operating framework: executive command, operations, revenue, client success, finance, compliance, HR/staffing, tech, marketing, contracting, partnerships, QA, and expansion.

Cloudflare Gateway

The deployable Worker/D1/KV/Queue backend layer for persistence, approvals, ledgers, customer commands, and admin routing.
