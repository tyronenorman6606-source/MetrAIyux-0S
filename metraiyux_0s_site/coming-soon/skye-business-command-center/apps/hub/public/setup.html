Operator-only deployment walkthrough

Take the stack from ZIP file to sellable production instance.

This page walks through server prep, environment setup, Docker launch, DNS/HTTPS, app installers, smoke testing, backups, and client handoff. Keep this page internal unless you intentionally publish it as a setup guide.

Expected monthly cost

Budget before deploying.

For one serious small-business production instance, budget a practical range of $60–$120/month. Ultra-lean testing can run closer to $30–$50/month. Multi-client agency hosting should budget $150–$400/month until client isolation and usage are measured.

Deployment runbook

Follow this order. Do not skip proof checks.

01

Prepare the server

Use Ubuntu 22.04/24.04 on a VPS with at least 2 vCPU and 4 GB RAM. For serious production, use 4 vCPU and 8 GB RAM. Enable a firewall and allow SSH, HTTP, and HTTPS.

sudo apt update
sudo apt install -y ca-certificates curl git unzip ufw
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw --force enable
02

Install Docker

The stack is Docker Compose based. Install Docker Engine and verify the daemon is running before touching app configuration.

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
docker --version
docker compose version
03

Unpack the build

Upload the ZIP to the server, unzip it, enter the project directory, and create your live environment file.

unzip skye-business-command-center.zip
cd skye-business-command-center
cp .env.example .env
bash scripts/generate-secrets.sh
04

Edit environment variables

Open .env and set real passwords, app domains, SMTP values, URLs, and any provider keys. Do not use placeholder secrets in production.

nano .env
bash scripts/preflight.sh
05

Launch the containers

Pull images, build the branded hub, start the stack, and confirm every container is running.

docker compose pull
docker compose up -d --build
docker compose ps
06

Run smoke checks

Smoke checks confirm that the public hub and service ports respond. This is not a substitute for full app installer completion, but it catches dead containers and broken routes.

bash scripts/smoke.sh
07

Configure DNS and HTTPS

Point domains or subdomains to the VPS. Use the included Caddy template for automatic HTTPS, then replace local dashboard URLs with production URLs.

cp deploy/caddy/Caddyfile.example Caddyfile
nano Caddyfile
# then run your chosen Caddy deployment method
08

Complete each app installer

Open each internal module and finish its built-in setup. Create operator/admin users, confirm database connections, set business branding, and configure SMTP where required. These are not customer signup links.

FreeScout -> EspoCRM -> InvoiceShelf -> Formbricks ->

Open branded operator tools page

09

Set up the sellable workflows

This is where the package becomes worth money. Customize the CRM pipeline, support inbox, intake forms, invoice branding, staff permissions, and client handoff SOPs.

  • Support mailbox connected
  • CRM stages renamed for the client
  • Quote request form published
  • Invoice and estimate templates branded
  • Owner and staff accounts created
  • Dashboard links changed to production domains
10

Backups and handoff

Run an initial backup, document restore notes, confirm credentials are stored safely, and give the client a clean walkthrough instead of technical noise.

bash scripts/backup.sh
ls -lah backups/
