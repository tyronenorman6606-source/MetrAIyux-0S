# SkyeMediaCenter Experience System

This build intentionally rejects the normal admin-dashboard pattern.

The app is shaped around seven route metaphors:

1. **Nerve** — main command cortex and app entry.
2. **Signal Atlas** — orbital asset map.
3. **Flow Reactor** — review, execution, dispatch, and timeline operating lanes.
4. **Vault Loom** — media records and asset matter.
5. **Runtime Spine** — function routes and runtime contract visibility.
6. **Proof Forge** — verified proof plus explicit not-proven boundaries.
7. **Control Core** — browser-local operator receipts and surface controls.

Public surfaces:

- `public/index.html` is the Asset Drop Reactor.
- `public/admin.html` is the Operator Theater.

Runtime surfaces remain powered by Netlify Functions under `netlify/functions`.
