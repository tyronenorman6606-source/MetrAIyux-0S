Reape0r: the Autonomous Cloud Repo Mirror

This is the paid workspace delivery room for Reape0r. He keeps one encrypted mutable current mirror of the repo. The first run seeds it, later runs replace changed encrypted objects inside that same current mirror, and deleted files leave the current restore view. Buyer upload uses the SkyePay-provisioned workspace portal key; owner/admin lanes can also pass the shared FS27/SkyGate bearer. No separate SkyeVault password is created here.

Manual Install Commands

tar -xzf skyevault-agent-latest.tar.gz cd skyevault-agent npm install --omit=dev node bin/skyevault-agent.mjs doctor export SKYEVAULT_PORTAL_KEY="<workspace portal key>" export SKYEVAULT_AGENT_PASSPHRASE="<customer-owned unlock passphrase>" # Optional for owner/admin or stricter deployments: export SKYEVAULT_GATE_BEARER="<shared FS27/SkyGate bearer>" node bin/skyevault-agent.mjs init --workspace=my-company --repo=/path/to/repo --vault-url=https://skyevault-drop.graylondonskyes.workers.dev node bin/skyevault-agent.mjs sync --upload node bin/skyevault-agent.mjs watch --interval-seconds=600 --upload node bin/skyevault-agent.mjs verify --receipt=/path/to/current-receipt.json node bin/skyevault-agent.mjs restore --receipt=/path/to/current-receipt.json --out=/tmp/restored-repo

Auto-Install Add-On Command

This is the $13 lane: the installer writes the env file with private permissions, configures the repo, runs doctor, seeds the encrypted mutable current mirror, and starts the watcher service when the machine supports it. Normal terminal output shows the receipt path, restore kit path, sync counts, and next commands; add --json when automation needs the raw receipt.

tar -xzf skyevault-agent-latest.tar.gz cd skyevault-agent SKYEVAULT_AGENT_AUTO_INSTALL=1 \ SKYEVAULT_WORKSPACE_ID="<workspace id>" \ SKYEVAULT_REPO_PATH="/path/to/repo" \ SKYEVAULT_DROP_URL="https://skyevault-drop.graylondonskyes.workers.dev" \ SKYEVAULT_PORTAL_KEY="<workspace portal key>" \ SKYEVAULT_AGENT_PASSPHRASE="<customer-owned unlock passphrase>" \ ./install.sh

What the package contains

Portable Node CLI, local encryption, upload session client, auto-install, mutable current sync, verify, restore, doctor/status/watch commands

The default current mirror is literal repo custody: committed Git state, untracked files, dirty worktree files, and the `.git` directory. The agent only skips its own output directories unless the buyer runs `--skip-deps`. Future syncs upload changed encrypted current objects and keep one current restore receipt. Buyer uploads work with the portal key SkyePay provisions for that workspace.
