Sentry-style lane, 0S-owned

SkyErrors captures app failures without creating a new auth lane.

SkyErrors is the first-class error ledger for 0S surfaces and customer apps. The capture API uses the shared FS27/SkyGate/Free99 session, stores recent errors in the SkyErrors/Helper K4i receipt lane, and mirrors records into CitadelDB when the D1 binding is present.

Drop-in SDK

import { createSkyErrorsClient } from "../sdk/src/index.js";

const skyerrors = createSkyErrorsClient({
  token: gateSessionToken,
  zeroOsUrl: "https://metraiyux-0s-full-system.graylondonskyes.workers.dev",
  service: "customer-app",
  release: "2026.05.24"
});

skyerrors.installGlobalHandlers();
skyerrors.captureException(error, { tags: { surface: "checkout" } });
