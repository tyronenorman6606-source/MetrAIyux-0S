First run

Launch the console, pick the workspace, then run the room.

  1. Open Console.Paste the Cloudflare `PLATFORM_ADMIN_TOKEN` secret.
  2. Select workspace.Use 0S, Bob, Empire, or a newly created customer lane.
  3. Read and reply.Open a real conversation, inspect source metadata, and answer as operator.
  4. Route memory.Turn business follow-up into a ConnectLog card, request, or opportunity.
