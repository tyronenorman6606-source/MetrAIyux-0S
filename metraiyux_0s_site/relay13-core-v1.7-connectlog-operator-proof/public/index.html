Owned messaging infrastructure

One relay.
Every app, inbox, and workspace.

Relay13 is the Cloudflare-native messaging platform for routing real conversations from websites and apps into a controlled operator console. It uses workspace-scoped APIs, hashed API keys, indexed D1 storage, Durable Object live threads, and configurable widgets.

Workspace routing Each company, client, or internal app runs under its own workspace scope instead of sharing one messy inbox.
Owned API access Other apps call Relay13 through scoped keys. Raw keys are generated once and only hashes belong in D1.
Widget publishing Workspace widget settings are published as config versions, so client branding can change without rebuilding the platform.
Cost discipline Indexes, workspace-scoped queries, text-only V1, and hibernation-ready live rooms keep infrastructure lean.
First run

Launch the console, create the workspace, then publish the widget.

  1. Open Console.Paste the Cloudflare `PLATFORM_ADMIN_TOKEN` secret.
  2. Bootstrap or create workspace.Relay13 keeps conversations, keys, widget config, and domains scoped by workspace.
  3. Allow domains.Add the website domains that are allowed to load that workspace widget.
  4. Generate API keys.Copy each raw key once into the calling app environment.
