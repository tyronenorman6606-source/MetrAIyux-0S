Vault key card handoff
Production workspace creation now issues a SkyeMail Vault Key Card at the same time it creates the client workspace and email record. The card is a resume-style credential packet for the client: workspace identity, SkyeMail address, vault setup URL, recovery policy, and security model. It does not contain private keys or passphrases. When the MDP/MCP webhook is configured, the card packet is sent to that server for branded rendering.
