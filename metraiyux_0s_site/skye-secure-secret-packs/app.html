SkyeSecure Console

Use this page when you have a downloaded `.skyesecrets` file. The file opens here, the passphrase unlock happens here, and restored files download from this browser only.

Local crypto plus proven handoff Selected files, packs, passphrases, and peppers stay inside this browser session. SkyeVault proves custody and download access; it does not store the plaintext or the pack passphrase.

If you came from SkyeVault

Open the downloaded secure pack here

Choose the `.skyesecrets` file you just downloaded, inspect it, then enter the recipient passphrase. If the pack says pepper is required, enter that too.

  1. Click Pack file and select the downloaded `.skyesecrets` file.
  2. Click Inspect to see the safe manifest and the recipient IDs.
  3. Enter the matching recipient ID, passphrase, and optional pepper.
  4. Click Unlock. Restored file downloads appear only after the cryptographic checks pass.
No passphrase?

If you did not create the pack and nobody gave you the passphrase, this browser cannot decrypt it. Ask the sender/admin for the pack passphrase and pepper, or use the operator CLI lane for packs created with public-key recipients.
