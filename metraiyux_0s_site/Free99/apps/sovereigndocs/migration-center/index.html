Migration checklist

No public compliance claims should change when the data moves from local JSON to Neon.

  • Import categories and jurisdictions.
  • Import template index records.
  • Import raw template JSON or keep object-storage pointers.
  • Import official workflows separately from generated templates.
  • Import review decisions and preserve high-risk gates.
  • Run npm run validation:all after seeding.
