# SovereignDocs v13 Workflow Surface Push

This push keeps SkyeDocx Max as the serious document editor and adds workflow surfaces around it.

Implemented surfaces:

- Customer dashboard using `/api/workspace/summary`.
- Packet builder using `/api/packets/assemble`.
- Reminder center using `/api/reminders`.
- Partner workbench using `/api/legal-review/submissions`.
- Template operations using `/api/template-ops/summary` and patch request endpoints.
- SkyeDocx Max handoff using `/api/editor/skye-docx-max/session`.

The platform remains self-help document automation, not a law firm and not legal advice.
