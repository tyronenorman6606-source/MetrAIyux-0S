# SovereignDocs Public Claims Ledger

## Allowed claims

✅ SovereignDocs is self-help document automation.
✅ SovereignDocs is not a law firm and does not provide legal advice.
✅ The v6 platform indexes 10,200 generated template records from the v2.1 confidence-review library.
✅ The platform includes official-source prep workflows that route users to current official sources.
✅ The platform includes high-risk review gates.
✅ The optional API can assemble documents and export DOCX after boundary acceptance.
