# SovereignDocs v4 Platform Expansion

This pass adds real page families and data-backed navigation layers.

## Added

- `20` document packets from `data/packs.json`
- `12` industry workspaces from `data/industries.json`
- `51` state/jurisdiction workspaces from `data/jurisdictions.json`
- Feature pages: `/features/`, `/exports/`, `/signing/`, `/integrations/`, `/compliance/`, `/operator-manual/`
- Optional Node API endpoints for packets, industries, and jurisdictions
- Stronger multipage and dataset smoke tests

## Boundary

State pages are navigation and organization surfaces only. They do not claim local legal validity, legal advice, attorney review, or enforceability.
