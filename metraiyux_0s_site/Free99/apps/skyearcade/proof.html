What changed

SEO, GEO, and AI-readable additions.

Playable vault

The app retains ten playable game doors and moves the launcher to /app.html so the root URL can rank as a public landing page.

SEO pages

The package now includes a home page, ten individual game pages, proof page, robots.txt, sitemap.xml, llms.txt, llms-full.txt, and ai.md.

Structured data

The landing page includes SoftwareApplication and FAQPage JSON-LD. Each game page includes VideoGame JSON-LD.

No auth added

The build keeps the no-auth posture. Progress remains local and upstream auth can inherit later.

PWA remains intact

Manifest, service worker, install icons, asset caching, Netlify headers, and app routing remain packaged.

Proof harness retained

The Playwright smoke harness remains in /tests for local or deployed click-smoke.
