Local confidence model

Private by product posture, not by vague marketing.

The app is designed to run locally first. The optional Node runtime writes to its own local data folder, and the browser-only mode exports portable JSON. There is no third-party database, cloud sync, telemetry, analytics tracker, or outside storage wired into this package by default.

Boundary: this package does not claim HIPAA certification, medical advice, billing advice, legal advice, or EHR replacement status. It is a personal workflow companion.
