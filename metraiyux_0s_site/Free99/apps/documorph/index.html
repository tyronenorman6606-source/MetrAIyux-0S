FAQ

Answers

Do I need an account?

No. The core app runs offline-first and stores your documents on your device. Cloud sync is optional.

Does it work offline?

Yes for the app shell and stored documents after first load. AI synthesis requires internet access.

What gets sent to AI?

Only the extracted text needed for the analysis prompt. Server Mode keeps your keys on the backend.

Can I sync across devices?

Yes with Neon Cloud mode enabled (requires server functions + Neon database).
