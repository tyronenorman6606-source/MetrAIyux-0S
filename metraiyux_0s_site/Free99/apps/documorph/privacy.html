Privacy Policy

Last updated: 2026-05-10

DocuMorph is an offline-first web app. By default, it stores your documents and generated study assets locally on your device (IndexedDB). You can use the core app without an account.

What data is stored

  • Uploaded PDF filename
  • Extracted text and detected sections
  • Generated summary, flashcards, and quiz questions
  • App preferences (selected AI engine, storage mode)

AI processing

When you run synthesis, DocuMorph sends the extracted text (or a portion of it) to the AI engine you select. If you use Server Mode, the request is routed through the DocuMorph backend so your API keys do not live in the browser. If you use Local Key Mode, your browser calls the provider directly using the key you paste in Settings.

Optional Neon cloud sync

If you enable Neon Cloud mode, documents are saved to a Neon Postgres database via the DocuMorph backend. Cloud sync is optional; local storage remains available regardless.

Third-party services

Depending on your configuration, DocuMorph may communicate with AI providers (Gemini or OpenAI) and a database provider (Neon). Their handling of data is governed by their own policies.

Contact

DocuMorph is published by SKYESOVERLONDON. For privacy questions, use the contact method provided on the deployment site.
