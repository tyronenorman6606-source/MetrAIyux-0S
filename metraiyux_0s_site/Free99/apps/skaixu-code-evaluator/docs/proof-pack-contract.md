# Proof Pack Contract

The **Export proof pack** action produces deterministic local evidence. It is designed for handoff and sanity checking, not for pretending live provider proof exists.

Included files:

- `proof/README.md`
- `proof/project-summary.txt`
- `proof/proof-ledger.json`
- `proof/seed-registry.json`
- `proof/upstream-auth-contract.json`

The proof pack can show:

- Deterministic code score.
- Platform readiness score.
- Route/link inventory.
- UI/runtime action inventory.
- Referenced environment variables.
- Public claim words that may need proof.
- Seed pipeline presence.
- Gateway-only direct endpoint scan.

The proof pack does not prove:

- Live deployment.
- Live gateway credentials.
- Payment/provider billing correctness.
- Browser automation against a production URL.
- Compliance or legal guarantees.
