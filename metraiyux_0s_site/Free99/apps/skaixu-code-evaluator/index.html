From repo drop to operator handoff.

The workflow is designed around closure pressure: load the code, prove the state, generate fixes, and export artifacts that show what changed.

1

Load

Drop a project folder or zip, then let the workspace registry index files, routes, actions, and environment requirements.

2

Evaluate

Run deterministic checks for risk, public claims, seed readiness, provider posture, framework adapters, and missing platform surfaces.

3

Patch

Queue issue-driven patch bundles, validate them, apply safe workspace changes, and preserve receipts for the task loop.

4

Export

Export the patched project, generated data, proof pack, build receipts, and operator-ledger files for the next implementation pass.

Proof-first by design.

The product avoids inflated completion claims. It separates deterministic local proof from live-provider proof, browser proof, and deployment proof.

Deterministic scansRoutes, links, actions, risky APIs, secret-like strings, env contracts, docs gaps, and public-claim words.
Receipts over memoryBuild runs, task loops, closure checks, and browser-proof attempts write machine-readable receipts.
Inherited identity contractThe platform is ready for an upstream shell to provide tenant, user, role, and entitlement context without adding a redundant login wall.
Gateway-routed model callsBrowser surfaces are designed to talk through the configured gateway path rather than direct model-provider endpoints.

FAQ

Clear product boundaries. No theater. ⚡

Is this the evaluator app or just a marketing page?

This page is the public website. The operator console lives at app.html and contains the actual workspace tools.

Does it require built-in auth?

No. The app is designed to inherit upstream identity from a parent shell, including tenant, user, and role context.

Can it process seed data?

Yes. It supports manifest-driven seed assets and generated platform data with duplicate detection, chunk manifests, and provenance files.

Does browser proof always pass?

No. Browser proof requires Playwright in the runtime environment. When unavailable, the app writes an honest skipped receipt instead of claiming a pass.
