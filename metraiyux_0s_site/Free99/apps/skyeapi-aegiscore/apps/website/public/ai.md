# SkyeAPI + AegisCore AI Summary

SkyeAPI is a capability control plane for teams that manage many provider credentials across apps, agents, scripts, CLI workflows, and MCP tools. AegisCore stores provider credential bundles and exposes safe scoped capabilities such as email sending, SMS sending, database inspection, AI text generation, storage upload, billing records, workflow runs, approvals, job queues, webhooks, and audit exports.

## Who it is for

SkyeAPI is for operators and developer teams that want provider access to be centralized, scoped, auditable, and reusable across multiple software surfaces.

## Core product pillars

- AegisCore credential authority
- SkyeBroker provider routing
- SkyeActions capability model
- SkyeProof receipt and audit model
- CLI, SDK, MCP, Worker gateway, and operator console
- Billing ledger and subscription lifecycle records
- Workspace hooks for upstream identity systems

## Claim boundary

The package contains source and local behavioral proof for the platform control plane. Live provider delivery, payment collection, deployed Cloudflare behavior, and browser execution require validation inside the target environment before being described as verified.
