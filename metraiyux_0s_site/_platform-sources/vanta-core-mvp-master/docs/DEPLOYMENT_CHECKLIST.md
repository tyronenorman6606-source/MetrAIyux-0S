## Pre-Flight

Run the preflight script locally or in CI before every deploy:

```bash
npm run preflight:strict
```

Exit code `0` = green light. Exit code `1` = fix before deploying.

- `Critical` = the preflight script will block deployment if missing in production.

## Platform-Specific Injection

### Netlify
1. Go to **Site configuration → Environment variables**.
2. Add all `[BUILD]` and `[RUNTIME]` variables.
3. Ensure `NODE_ENV=production` is set.
4. Trigger a new deploy.

### Cloudflare Pages
1. Go to **Workers & Pages → vanta-core → Settings → Environment variables**.
2. Add variables to **Production** and **Preview** environments.
3. Add `compatibility_flags = ["nodejs_compat"]` to `wrangler.toml` (already present in `cloudflare-pages.toml`).
4. Trigger a new deploy.

## Post-Deploy Verification

1. **Preflight** — run `npm run preflight` against the production env.
2. **Health check** — `curl https://<your-domain>/api/health` should return `200`.
3. **Smoke tests** — run `npm run test:smoke` pointed at the production URL.
4. **Webhook probes** — send test payloads to each webhook endpoint and verify `200` + signature acceptance.
5. **DNS / SSL** — confirm custom domain resolves and certificate is valid.

## Rollback Plan

1. Netlify: use **Deploys** panel → click previous deploy → **Publish deploy**.
2. Cloudflare Pages: use **Deployments** panel → select previous deployment → **Rollback**.
3. If database migrations ran forward, evaluate whether a rollback migration is needed before reverting code.
