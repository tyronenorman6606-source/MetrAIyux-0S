# Local Artist Inventory

This is the correction folder for the artists that are already local to Nexus, separate from the two founder provisions.

- `manifest.json` lists 23 live local Music Nexus artist records currently returned by the gated production artist API.
- It also lists 7 hardcoded legacy OneMusic popular-artist placeholders that are built into the old site surface.
- Keep production-ready artist storefront upgrades in the matching real artist folder when an artist becomes serious.
- Keep proof/smoke/live-browser records marked as proof until they are promoted, so the public storefront lane does not accidentally treat test records as customer artists.
