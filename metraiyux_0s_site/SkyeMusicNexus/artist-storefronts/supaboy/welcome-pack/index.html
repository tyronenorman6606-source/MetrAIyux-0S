how to upload a song

Use this order for the first SupaBoy upload.

Only upload music SupaBoy owns, controls, or has written permission to use. The public store stays locked until the file, rights, paperwork, and owner review are approved.

1

Open the gate.

Use the shared 0S/SkyGate session. No separate SupaBoy password exists.

Shared Gate
2

Open Upload Studio.

The SupaBoy link carries artist ID 444666666667 and the SLB release lane.

Open Upload
3

Pick the song file.

Drop or select WAV, MP3, FLAC, M4A, OGG, or WebM audio.

4

Name the track.

Use the track title. If it belongs to SLB, keep the project context attached.

5

Upload gated audio.

Press Upload Gated Audio. When it succeeds, copy the generated track line.

Upload Studio
6

Forge the release.

Open Release Forge, paste the generated track line, set type/date/targets, and save.

Release Forge
7

Save rights.

Use Rights Vault to confirm master ownership, preview use, distribution, samples, covers, publisher clearance, and takedown contact.

Rights Vault
8

Wait for owner review.

After owner approval, the track can attach to product cards, drops, playback, and checkout routes.
