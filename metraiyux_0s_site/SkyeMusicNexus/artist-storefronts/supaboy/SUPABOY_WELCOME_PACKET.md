## How SupaBoy Uploads A Song

1. Open the shared 0S/SkyGate session. No SupaBoy-only Music Nexus password exists.
2. Open Upload Studio with the SupaBoy link: `https://skye-music-nexus.pages.dev/public/upload.html?artist=supaboy&artistId=444666666667&releaseId=slb-superboy`.
3. Confirm Artist ID is `444666666667`. If it is blank, paste that exact ID.
4. Keep Release ID as `slb-superboy` for SLB / Superboy material, or use the owner-approved release ID for another project.
5. Choose an owned or properly licensed WAV, MP3, FLAC, M4A, OGG, or WebM file.
6. Enter the track title and press `Upload Gated Audio`.
7. Copy the generated track line after upload succeeds.
8. Open Release Forge, paste the generated track line, set release type/date/targets, and save the release capsule.
9. Open Rights Vault and save ownership, preview-use, distribution, samples, cover/mechanical, publisher clearance, and takedown contact details.
10. Wait for owner review before the uploaded song is attached to public playback, products, drops, checkout, or payout.
