Drop SupaBoy image assets in this folder.

The build picks up `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, and `.gif` files from here, copies them to `dist/media`, and maps them onto the floating stage surfaces and video wall.

Helpful filename cues:

- `sound-*`
- `stage-*`
- `video-*`
- `drops-*`
- `book-*`
- `portrait-*`
- `cover-*`
