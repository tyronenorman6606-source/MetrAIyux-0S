# CitadelDB Platform Closure

v1.9 turns CitadelDB from operator-first infrastructure into a real sellable database platform foundation.

## Added platform concepts

- accounts
- teams
- plans
- quotas
- project ownership
- usage snapshots
- quota events
- table browser
- table preview
- usage dashboard

## Why this matters

A Neon-like product needs more than database provisioning.

It needs:

- users
- teams/workspaces
- plans
- quotas
- usage tracking
- SQL console
- table browser
- project ownership
- billing hooks
- safe self-service

v1.9 adds those foundations.

## Still not fake

Billing enforcement is scaffolded, not wired to Stripe checkout/webhooks yet.

Usage metering is scaffolded, not full storage/compute billing proof yet.

Table Browser previews rows; it is not yet a full editable spreadsheet-like table editor.
