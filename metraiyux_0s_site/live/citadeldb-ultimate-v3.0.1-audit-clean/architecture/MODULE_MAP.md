# Module Map

## Citadel Core

Owns:

- tenants
- apps
- app environments
- database role lifecycle
- service catalog
- capacity/readiness API

## Reliquary

Owns:

- backup generation
- backup manifests
- restore receipts
- rollback receipts
- export bundles
- disaster recovery drills

## SceptR

Owns:

- safe command runner
- operator job queue
- migrations
- smoke tests
- proof scripts
- scheduled proof loops

## Veyra3.1

Owns:

- private route names
- pooler endpoints
- failover route promotion
- tunnel policy
- service discovery

## Aegis

Owns:

- env validation
- public bind checks
- credential rotation
- policy findings
- incident response
- access boundaries

## SkyLedger

Owns:

- audit events
- command receipts
- claims ledger
- proof receipts
- readiness gates
