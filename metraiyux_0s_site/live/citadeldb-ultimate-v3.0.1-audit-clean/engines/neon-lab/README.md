# Neon Lab

Non-production research lane.

This lane studies Neon-inspired patterns:

- branching
- compute/storage separation
- stateless compute
- pageserver/safekeeper concepts
- WAL durability patterns
- serverless connection patterns

## v0.2 rule

No production claim.

This lane can store research notes, experiments, and adapter compatibility tests. It is not the default database engine.
