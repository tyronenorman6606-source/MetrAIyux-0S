# Backup and Restore Acceptance

## Minimum

☐ backup receipt exists  
☐ backup file exists  
☐ backup manifest exists  
☐ restore-test receipt exists  
☐ integrity report exists  

## Paid-client

☐ offsite sync receipt exists  
☐ clean-server restore receipt exists  
☐ retention policy documented  
☐ incident response owner assigned  

## Claim language

Allowed:

```text
Backup and restore-test receipts exist for this deployment.
```

Not allowed without PITR receipt:

```text
Point-in-time recovery is proven.
```
