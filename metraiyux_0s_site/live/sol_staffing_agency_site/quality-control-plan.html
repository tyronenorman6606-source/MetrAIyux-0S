Quality Control Plan

Staffing Quality-Control Plan Shell

A buyer-facing structure for performance discipline, issue management, replacement workflow, and documentation. Replace placeholders before proposal submission.

Purpose

The purpose of this quality-control plan is to define how Skyes Over London Staffing manages staffing intake, candidate screening, assignment readiness, communication, issue resolution, replacements, and performance follow-up.

Account Ownership

Each client account should have a named account owner responsible for communication, job-order updates, escalation, feedback, and follow-up.

Job Order Control

Every assignment should begin with documented role requirements: duties, headcount, location, shift, pay range, start date, required skills, safety requirements, onboarding steps, and supervisor contact.

Candidate Screening

Candidates should be screened for availability, location fit, schedule fit, experience, communication readiness, pay expectations, and role-specific requirements.

Assignment Readiness

Before start, candidates should receive reporting location, contact person, shift details, dress code, required items, attendance expectations, and communication instructions.

Issue Resolution

Issues should be logged, assigned an owner, categorized, and followed until closed. Urgent issues should be escalated to account leadership.

Replacement Process

Replacement obligations depend on the client agreement. When replacement is appropriate, the agency should confirm the issue, update the job order if needed, source replacement candidates, and communicate timeline.

Performance Review

Account feedback should be reviewed to improve job-order quality, sourcing strategy, candidate preparation, and client communication.
