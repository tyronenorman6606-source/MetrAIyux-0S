Candidate Onboarding

Prepare candidates before assignment starts.

This page defines the candidate onboarding pack. It helps reduce missed starts, confusion, missing documents, and expectation mismatches.

Candidate Readiness

Clear instructions reduce failure.

Production onboarding should route through secure document collection and verified employer requirements.

Before Assignment

  • Confirm start date
  • Confirm location
  • Confirm supervisor / check-in contact
  • Confirm dress code or PPE
  • Confirm shift and break expectations

Documents

  • Resume or work history
  • Identity/work eligibility docs through secure process
  • Certifications if required
  • Background-check authorization if applicable
  • Client-specific forms if applicable

Communication

  • Keep phone active
  • Respond quickly
  • Report issues early
  • Confirm arrival
  • Notify staffing contact before absence
