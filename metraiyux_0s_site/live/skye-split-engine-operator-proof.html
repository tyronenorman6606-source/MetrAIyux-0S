Skye Split Engine is Free99, meaning no charge, and it still requires a gate session.

Workflow

What it does

  • Define people, products, and reusable split rules.
  • Log transactions and preview percent, fixed, and remainder payout lines.
  • Run settlement reports, export payout sheets, and mark ranges settled.
  • Back up local records, restore JSON, keep snapshots, and run data repair.

Boundary

What it does not claim

  • It does not move money, run payroll, file taxes, or replace accounting/legal review.
  • It does not sync private split records to cloud storage unless a later approved scope wires that provider.
  • It does not bypass auth because it is free.
