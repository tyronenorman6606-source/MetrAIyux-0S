Release proof

What shipped

Smart Git remote

Real Git smart HTTP push, fetch, and clone against persistent bare repos under each workspace and repo id.

Gate isolation

Gate token introspection, workspace scoping, admin/viewer roles, wrong-workspace rejection, and protected operator APIs.

Policy enforcement

Protected main/master refs, protected release tags, denied deletes, denied unsafe force pushes, and persisted branch-policy config.

Quota enforcement

Repo/workspace byte accounting and post-pack quota checks exposed through operator quota APIs.

Snapshots

Verified Git bundle snapshots with checksums, manifests, optional mirror root, verify endpoint, and local maintenance restore command.

Developer interface

CLI login/clone/status/snapshot/policy/quota/diff, credential helper, and SSH forced-command wrapper.

Brain maps

Aggregate SkyeVault map plus per-workspace map files so one account sees its own repos, uploads, graph nodes, and change timeline.

Browser proof

The operator neural map and account workspace UI were checked in browser for repo rows, graph nodes, upload rows, console errors, and overflow.
