Fast lane

One terminal command that clones if missing and pulls if already present

Use this on macOS, Linux, WSL, or a Codespace terminal. It keeps one local folder at ~/Projects/MetrAIyux-0S and opens it in VS Code.

Bash / Zsh / WSL
REPO_URL="https://github.com/tyronenorman6606-source/MetrAIyux-0S.git"
DEST="$HOME/Projects/MetrAIyux-0S"
mkdir -p "$HOME/Projects"
if [ -d "$DEST/.git" ]; then
  cd "$DEST"
  git switch main
  git pull --ff-only origin main
else
  git clone --progress "$REPO_URL" "$DEST"
  cd "$DEST"
fi
code .
Use this most of the time. It avoids nested folder bloat, keeps Git history intact, and updates cleanly without redownloading the whole project every time.

Vault boundary

What Git covers versus what the vault covers

  • Git is the source of truth for code, docs, public-safe receipts, handoffs, and tracked assets. Use it for every new Codespace and local VS Code setup.
  • Ignored local files are intentionally not in Git. That includes .env, raw provider keys, private keys, local browser caches, dependency folders, large archives, and secret vault material.
  • The full workspace vault lane is different. Encrypted full-repo artifacts ending in .zip.enc need the matching direct restore kit before they become a real ZIP.
  • Do not commit secrets. If the next operator needs private credentials, they must use the shared 0S/FS27/SkyGate/Free99 gate lane or owner-approved vault recovery, not a new app-specific password.
