# V12 Monetization and Closure Notes

The current package remains playable offline without a payment backend. The $13/year lane should sell expansion, continuity, and care rather than pay-to-win power.

Clean paid expansion ideas:

- seasonal Chronicle arc packs
- subscriber companion skins and emotes
- cloud backup/sync
- expanded audio packs with clean licensing
- real leaderboard seasons
- cosmetic trails, frames, and title cards
- advanced analytics and coach plans
- new Focus Card / Run Lab / Campaign expansions

Do not ship random third-party music into a paid build unless the license is confirmed. The included ambience loops are original generated WAV files, and the documentation keeps external audio imports separate.

Remaining closure before charging users: deploy to HTTPS, test iOS and Android install flows, run long phone sessions, tune rewards, and add a real account/payment/sync lane if paid subscriptions are collected.
