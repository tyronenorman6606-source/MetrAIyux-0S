# Audio Licenses and Sources

## Embedded audio in this package

The five files in `assets/audio/` were generated specifically for this build as original procedural ambience/binaural-style loops:

- `alpha-calm-8hz.wav`
- `theta-drift-4hz.wav`
- `focus-gate-14hz.wav`
- `delta-night-2hz.wav`
- `rift-spa-6hz.wav`

These embedded files are released inside this project under CC0-style internal project terms: commercial use allowed, no attribution required, editable, removable, and replaceable.

These are entertainment/background-focus tones only. Do not market them as medical treatment, therapy, sleep cure, anxiety treatment, ADHD treatment, or any other health claim.

## Verified free/open audio sources researched for expansion

These sources were researched as clean expansion candidates:

- Kenney Music Jingles — Creative Commons CC0. Good for UI/game stingers and bonus jingles.
- Kenney Sound Pack / UI Audio — Creative Commons CC0. Good for button, reward, lock, and interface sounds.
- OpenGameArt CC0 Music collection — OpenGameArt hosts many free cultural/open-game assets; individual pages must be checked before embedding.
- OpenGameArt “Dream Ambience” by TokyoGeisha — listed as CC0 with no credit necessary. Good candidate for ambient expansion.

## Import rule

Before adding any third-party MP3/WAV/OGG into `assets/audio/vendor/`, check the individual asset page and record:

1. Asset title
2. Author
3. License
4. Source URL
5. Whether attribution is required
6. Date imported

Do not import “royalty-free” assets unless commercial game redistribution is clearly allowed. Do not import Creative Commons NC or ND assets for this product.
