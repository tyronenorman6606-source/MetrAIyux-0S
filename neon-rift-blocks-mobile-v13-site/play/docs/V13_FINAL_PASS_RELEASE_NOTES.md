# V13 Final Pass Release Notes

Gravity Protocol v13 is the release-candidate hardening pass. It does not pretend the game is server-backed or app-store-shipped yet. It adds product-grade local systems that support a $13/year annual pass after live phone testing.

## Added in v13

- Final Pass Console opened from the header, home overlay, and profile.
- Release checklist covering first run, mood setup, Signal Chest, backup export, Zen Flow, Run Receipt, and annual-value review.
- Player-first release oath to document the paid-tier promise.
- Founder Kit claim that unlocks Singularity Gold, Crown Glass RC, and Aura Wave cosmetics locally.
- Session Quality and Value Score metrics that grow from real play, not fake server counters.
- Wellness reset action that rewards a small shard and reinforces long-session comfort.
- Fixed v12 end-run reward wiring so Crown/Mood rewards are evaluated before shard calculation.

## Paid-product stance

The core game should remain playable. Annual subscription value should come from rituals, premium challenge lanes, seasonal cosmetic drops, convenience, profile continuity, and continued development. Avoid pay-to-win locks.
