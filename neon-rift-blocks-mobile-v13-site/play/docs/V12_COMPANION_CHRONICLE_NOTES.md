# V12 Companion / Chronicle / Aftercare Notes

Version 11 adds retention systems that are wired into runtime and local profile data:

- Rift Companions: unlock/equip companions, earn affinity after runs, and apply small mode-aware run bonuses.
- Rift Chronicle: selectable story arcs with run goals, XP payouts, shard payouts, and achievements.
- Post-Run Aftercare: a recovery choice after each run so losing still converts into affinity, serenity, shards, or run memories.
- Local Run Memory Bank: short local notes from analysis actions; no account or server needed.
- v12 profile key: `nrb_profile_v12`, with migration from v2-v12 local profiles. v12 companion/chronicle systems are retained inside v12.

Commercial value: these systems create identity, collection, recovery, and story progression without selling power, gambling mechanics, or requiring backend accounts.
