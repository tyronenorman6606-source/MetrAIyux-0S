Why scoped

It reduces confused output.

A sales request should not sound like compliance. A customer support request should not bypass security. Scoped brains make routing explainable.

Why local

It keeps doctrine close.

The full site includes JSON and markdown brain files so the system can retrieve company context without needing a live provider for every public interaction.

Why gated

It protects authority.

0meg4kAI exists because customer workspaces and the owner command layer must not share unchecked access.
