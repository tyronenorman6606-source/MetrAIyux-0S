# User Guide: Skye Design MCP

This MCP helps users and agents create better public websites, client pages, product pages, and app surfaces.

## What It Does

It gives agents access to:

- Approved design rules.
- Skye/Spectacle style references.
- Cinematic layout patterns.
- Copy safety rules.
- Browser QA requirements.

## How To Use It

Ask your agent to use the design MCP before building or editing a public page.

Good prompt:

```text
Use the Skye Design MCP. Build a premium product page using the full-width command hero and scrolling proof funnel. Check mobile and desktop in browser before deploy.
```

Bad prompt:

```text
Make me a landing page.
```

## What You Should Expect

A good generated page should:

- Have a strong first impression.
- Use short, expensive-feeling copy.
- Show a real subject, product surface, founder image, or proof artifact.
- Work on mobile.
- Avoid ugly text columns.
- Avoid internal debug/proof language.

## What To Reject

Reject the output if:

- The headline stacks down the page.
- The image looks random or pasted in.
- The first screen is mostly paragraph text.
- Mobile has horizontal scroll.
- Public copy mentions MCP smoke tests or internal artifacts.

## For Client Access

Users do not need to understand MCP internals. Tell them:

> This design system keeps our pages premium, mobile-safe, and proof-aware before anything goes live.
