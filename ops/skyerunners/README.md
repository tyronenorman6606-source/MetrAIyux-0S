# SkyeRunners Runtime State

This folder is the repo-local queue and receipt lane for `tools/skyerunners.mjs`.

- `ledger.ndjson` is generated at runtime and intentionally ignored.
- `queue/*.json` task files are generated by the local admin bridge and intentionally ignored.
- The public-safe runner map is written to `metraiyux_0s_site/brain/skyerunners.json`.
