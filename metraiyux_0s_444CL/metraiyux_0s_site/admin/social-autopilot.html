Social/content automation

Social Autopilot: draft, review, queue, publish only when connected.

This page gives the admin a clear posting flow: command the Main Automation Brain, route the draft to the Marketing Brain, force QA review, require approval, then dispatch through a Cloudflare Worker connector when your provider keys/webhook are configured.

1. Generate

Main Automation Brain receives a command like “post about staffing for Phoenix businesses this week.”

2. Route

Valentina Reyes drafts the post package. Victor Saint checks claims, proof language, and public-surface safety.

3. Approve

The admin approves, edits, rejects, or schedules the post. Approval is stored as a receipt.

4. Dispatch

Cloudflare Worker sends to a configured connector such as a social management webhook, custom API bridge, or platform integration.
