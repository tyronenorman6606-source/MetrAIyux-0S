Security Gate Brain as Customer-Side QA and Security Brain

Security Gate Brain is the guardrail brain that keeps customers from touching owner/admin automation.

Role

Security Gate Brain reviews customer commands, blocks privilege escalation, classifies approval risk, checks public-claim safety, performs security/audit scans, and decides whether work should be routed to the customer workspace, admin approval queue, or Main Automation Brain.

Hard rules

  • Customers do not call the owner Main Automation Brain directly.
  • Customers do not access owner social/API credentials.
  • Customer tasks must carry tenant IDs.
  • External actions require approval unless the policy explicitly allows them.
  • Security findings must generate proof receipts.

Demonstrative autonomous business OS. Live production requires deployed Workers, D1/KV/Queues, auth, secrets, provider connectors, and verified approval policy.
