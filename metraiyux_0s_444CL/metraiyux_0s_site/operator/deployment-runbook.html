Deployment Runbook

Static Deployment

  1. Extract the ZIP.
  2. Use the inner metraiyux_0s_site folder as the publish root.
  3. No install command is required.
  4. No build command is required.
  5. Deploy to Netlify Drop, Cloudflare Pages, Vercel static, or any static host.

After Deploy

  1. Open the homepage.
  2. Click Governance, Pricing, Brain, Blog, Recruiting, Proof, and Operator pages.
  3. Run the claims review before sales use.
