For serious production tonight, each paying client should get a dedicated VPS or isolated compose project. Avoid shared databases across unrelated businesses until tenant isolation is formally engineered and tested.

Acceptance checklist

  1. Run bash scripts/preflight.sh.
  2. Run docker compose -f docker-compose.yml -f docker-compose.prod.override.yml up -d --build.
  3. Run bash scripts/acceptance.sh.
  4. Run bash scripts/backup.sh then bash scripts/verify-backup.sh ./backups.
  5. Run bash scripts/client-readiness-report.sh and archive the generated report.
