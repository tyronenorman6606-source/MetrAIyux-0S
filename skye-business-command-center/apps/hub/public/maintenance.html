Recurring revenue protection

Monthly support is a deliverable. Prove it.

Use this page to run recurring maintenance: uptime check, backups, updates, user cleanup, mailbox test, forms test, CRM review, invoice settings review, and client report.

Weekly

Health sweep

bash scripts/health-report.sh
docker compose ps
docker compose logs --tail=100

Check containers, disk, memory, and recent logs. Save the report.

Before updates

Backup first

bash scripts/backup.sh
bash scripts/update-stack.sh

Never update a client stack before taking a backup and confirming rollback path.

Recovery

Rollback path

bash scripts/rollback.sh
bash scripts/restore.sh backups/latest.tar.gz

Use rollback for failed image/config updates. Use restore only when data recovery is required.

Monthly client report

Send a short report: uptime status, backup date, open support issues, CRM pipeline notes, form submissions, invoice lane notes, and recommended workflow improvements. This makes the monthly fee feel concrete.
