# Fade Masters PHX — Open Source HD Barber Image Pack

This pack contains public-domain, CC0, and Creative Commons Attribution barber/barbershop images suitable for client-app mockups, booking pages, service cards, social posts, Google Business Profile-style visuals, and similar barbershop clients.

Folders:

- `01_HD_ORIGINALS/` — untouched source files downloaded from Wikimedia Commons.
- `02_WEB_READY_2400PX/` — resized/compressed JPEGs with max side up to 2400px for app/web use.
- `03_HERO_CROPS_1920x1080/` — ready-made widescreen hero/header crops.
- `04_SQUARE_CROPS_1600x1600/` — ready-made square crops for cards/social/profile modules.
- `CONTACT_SHEET.jpg` — quick visual index.
- `LICENSE_MANIFEST.csv` — structured source/license attribution table.

Usage rule: keep attribution visible or bundled wherever required by the license. CC0/public-domain files do not require attribution, but attribution is still included for clean recordkeeping. Derivative folders were resized/cropped/compressed from the originals.

I intentionally excluded the stricter ShareAlike images from the final pack so you have a cleaner client-safe default set.
