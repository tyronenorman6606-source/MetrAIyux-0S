# Vault Neural Map

The private neural map is the visual graph layer for this vault. It turns notes, wiki links, tags, folders, repo-source mentions, and brain-export status into an interactive canvas map.

## Open It

Open this local file in a browser:

```text
obsidian-vault/_neural-map/index.html
```

## Refresh It

Run the repo-local graph command after changing note links, tags, folders, or source references.

## What The Map Shows

- Hub node for the whole MetrAIyux 0S vault.
- Note nodes for each markdown file.
- Tag nodes for vault themes.
- Folder nodes for command, production, proof, sales, templates, and other lanes.
- Source nodes for referenced repo files and proof artifacts.
- Brighter brain-exported notes where `brain: true` is set.

## Exposure Rule

This map is private operator material. Keep it inside `obsidian-vault/_neural-map/` and outside public deployment paths unless the host has real auth.
