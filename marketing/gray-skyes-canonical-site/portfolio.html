Detailed Drinique MCP tech stack

Frontend build

  • Static HTML routes with semantic sections and direct production links.
  • CSS Grid/Flexbox layout, responsive bands, compact cards, and custom interaction states.
  • Canvas 2D visual systems for table, forge, and comparison scenes.
  • Vanilla JavaScript for forms, copy controls, mode state, hotspots, drawer panels, and route tabs.

MCP orchestration

  • SKRUCIBLE contract: forge palette, glass component direction, GSAP-scroll concept, kinetic wordmark, raw/refined mode.
  • Merser MCP4 contract: barbershop room archetype, source-world rule, sovereign hero slab, route selector, workspace dock, proof rail.
  • Quantumskyes mining receipt: 18 resources read, 27 tools listed, 34 tool calls, zero failed MCP calls.
  • Variant receipt documenting non-override policy and exact files shipped.

Interaction engineering

  • Pointer-event drag-to-pan room behavior and zoom controls.
  • Clickable service hotspots that open conversion drawers.
  • Scroll camera movement and auto drawer-close behavior off hero.
  • Responsive mobile fallbacks, reduced-motion handling, anchor navigation, and staged local request forms.

Deployment and proof

  • Cloudflare Pages project: `drinique-mcp-comparison`.
  • Canonical production URL plus immutable preview deployment.
  • Headed Chromium proof under Xvfb across desktop and mobile-sized viewports.
  • Screenshot, DOM, console, network, broken-media, visual-variance, and source-hash receipts.
