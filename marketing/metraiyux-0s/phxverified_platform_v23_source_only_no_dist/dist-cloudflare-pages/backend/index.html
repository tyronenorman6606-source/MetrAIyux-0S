Runtime mutation layer without fake live writes.

Rejects missing auth

The handler requires x-upstream-user-id or x-upstream-user-email unless local dev explicitly sets ALLOW_LOCAL_ACTIONS=true.

02

Idempotent queues

Action IDs are stable hashes so duplicate submissions do not create infinite review spam.

03

No fake mutation

Every action is queued for review. Static seed files only change after approved operator/backend workflows.
