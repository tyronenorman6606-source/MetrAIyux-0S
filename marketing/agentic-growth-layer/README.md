# Agentic Growth Layer Site

Public product site for the API-first self-improving website service.

Local preview:

```bash
python3 -m http.server 4328 --directory marketing/agentic-growth-layer
```

Service proof is generated from the package examples and stress receipt:

```bash
npm --prefix packages/agentic-growth-layer test
npm --prefix packages/agentic-growth-layer run build:site-data
```
