# SOL Staffing OS Valuation Brief

## Direct Position

SOL Staffing OS is a deployable staffing-agency front-end/business OS package.

It is not a finished payroll, EOR, workers comp, insurance, tax, legal, HR compliance, or enterprise ATS product.

It is a serious launch and operating layer for a staffing agency:

- public marketing website
- employer intake
- candidate workflow
- AE sales workflow
- government pursuit surfaces
- internal operator pages
- Skyegate FS27 auth bridge
- form-to-record backend
- secure upload vault
- admin dashboard
- local brain plus Ollama/GPU endpoint wiring

## Replacement Cost Estimate

Reasonable replacement-cost range: **$15,000-$45,000**

That range reflects:

- public page buildout
- responsive design system
- staffing-specific copy architecture
- internal workflow map
- Netlify Functions backend
- auth session bridge
- protected route layer
- record classification
- upload handling
- admin dashboard
- brain endpoint wiring
- documentation and smoke testing

## Suggested Sales Packages

### Launch Site

Suggested price: **$2,500-$5,000**

Includes public deployment, content replacement, basic form routing, smoke testing, and launch documentation.

### Live Staffing OS

Suggested price: **$7,500-$15,000**

Includes Skyegate FS27 auth setup, Netlify Functions, record collections, secure upload path, admin dashboard, live brain env configuration, and operator walkthrough.

### Managed Operator Support

Suggested price: **$1,000-$2,500/month**

Includes monthly workflow tuning, new pages/forms, dashboard improvements, brain corpus updates, and records/export support.

## Production Gaps To Disclose

- Real business identity must be verified before launch.
- Government claims must be verified before publication.
- Sensitive staffing documents require retention/access/legal review.
- Payroll, EOR, workers comp, tax, HR, and insurance operations are outside the package.
- Live brain requires configured Ollama or GPU endpoint.
- Skyegate FS27 auth requires the introspection URL environment variable.

## Sales Thesis

The buyer is not paying for a template.

The buyer is paying to avoid launching a staffing company with one inbox, one spreadsheet, and no operating trail.
