# App Cutover Acceptance

Use this for every app moved into CitadelDB.

## Required artifacts

☐ onboarding packet  
☐ source dump receipt  
☐ restore receipt  
☐ count verification receipt  
☐ migration receipt  
☐ app env file  
☐ app write-smoke receipt  
☐ post-cutover backup receipt  
☐ post-cutover restore-test receipt  
☐ rollback plan  

## Acceptance statement

```text
App APP_NAME is accepted on CitadelDB only after app write smoke, backup, and restore-test receipts exist.
```
