# CitadelDB First Run Guide

Open the dashboard and use these pages first:

```text
First Run
Guided Ops
Database Launchpad
AI Debug
```

## First Run

Shows what is configured and what is missing.

## Database Launchpad

Create app databases, rotate credentials, test DATABASE_URL values, and run write-smoke checks.

## Guided Ops

Run safe proof actions from buttons:

- validate env
- backup now
- restore test
- policy check
- backup manifest
- object backup sync

## Diagnostics

Create a redacted diagnostic bundle and send it to OpenAI or Gemini from the dashboard.

## Rule

Buttons enqueue proof actions. They do not fake success. Jobs and receipts decide what is proven.
