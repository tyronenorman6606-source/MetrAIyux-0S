# CitadelDB Ultimate by Skyes Over London

CitadelDB Ultimate is a sovereign database command infrastructure platform from Skyes Over London and SOLEnterprises. It is part of the SoveReign13 Infrastructure Family.

CitadelDB is designed to manage private database infrastructure through company-owned modules:

- Citadel Core: database, tenant, app, environment, and role registry
- Reliquary: backup, restore, export, rollback, and receipt ledger
- SceptR: provisioning, migration, safe job, smoke test, and proof command runner
- Veyra3.1: private routing, tunnel discipline, pooler endpoints, and failover route promotion
- Aegis: policy checks, credential rotation, exposure guards, and incident response
- SkyLedger: audit events, command receipts, claims ledger, and proof history

CitadelDB is proof-led. Public claims must match generated receipts. It is not positioned as a clone of any external database platform.
