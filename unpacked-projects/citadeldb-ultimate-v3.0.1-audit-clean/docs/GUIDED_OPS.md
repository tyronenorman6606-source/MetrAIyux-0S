# Guided Ops

Guided Ops is the dashboard-first operator layer.

## What it solves

You should not need to remember commands for normal database work.

Guided Ops gives you:

- setup checklist
- proof buttons
- diagnostic bundle
- AI debug handoff
- no-code database launch flow

## Proof actions

Each button creates a safe, allowlisted job.

The job result and receipt still decide truth.

## Diagnostic bundle

The bundle includes recent:

- apps
- jobs
- backups
- restores
- audit events
- policy findings

Secrets are redacted before being shown or sent to AI.
