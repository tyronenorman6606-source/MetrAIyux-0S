# Internal Research Policy

CitadelDB may study external projects and open-source infrastructure, but public product architecture must remain Skyes-owned.

## Allowed internal usage

- compare architecture patterns
- use replaceable deployment adapters
- track vendor manifests
- document implementation-specific setup
- cite license obligations where needed

## Not allowed public usage

- describing CitadelDB as a clone
- naming external projects as product pillars
- making external upstream architecture the CitadelDB architecture
- overclaiming features because upstream systems support them

## Public architecture source of truth

```text
architecture/CITADELDB_SOVEREIGN_ARCHITECTURE.md
PUBLIC_ARCHITECTURE.md
brand/BRAND_CONFIG.json
```
