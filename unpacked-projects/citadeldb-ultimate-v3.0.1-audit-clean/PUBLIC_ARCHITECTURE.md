# CitadelDB Ultimate

## Sovereign Database Command Infrastructure

CitadelDB Ultimate is a Skyes Over London / SOLEnterprises database command platform for private infrastructure, proof-backed operations, app database provisioning, backups, restores, migrations, routing, and recovery.

CitadelDB is part of the SoveReign13 Infrastructure Family.

## System pillars

```text
Citadel Core  — database, app, tenant, and environment registry
Reliquary     — backup, export, restore, rollback, and receipt ledger
SceptR        — provisioning, migration, safe jobs, smoke tests, and proof runner
Veyra3.1      — private routing, tunnel discipline, pooler endpoints, and failover routing
Aegis         — policy checks, credential rotation, exposure guards, and incident discipline
SkyLedger     — audit events, command receipts, claims ledger, and proof history
```
