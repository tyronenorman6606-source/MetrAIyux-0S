How it works

Provision, key, send, receive, prove.

1. 0S creates the workspaceThe SaaS worker provisions the client workspace, asks SkyeMail for an email identity, and stores the mailbox receipt.
2. SkyeMail issues a key cardThe card includes the mailbox, setup URL, recovery policy, and vault-key security model without exposing private keys.
3. Resend moves the emailOutbound messages and inbound webhooks pass through the verified Resend domain and land in SkyeMail monitoring.
4. Vault keys lock the inboxThe public key receives encrypted mail. The private key stays wrapped by the client passphrase.
5. Delivery events stay visibleSent, delivered, failed, bounced, and received events become proof records without exposing inbox content.
6. The client can replyThe proof surface shows a two-party exchange: A sends to B, B receives, B replies, A receives.
SkyeMail is the secure email workspace layer for MetrAIyux 0S clients.
