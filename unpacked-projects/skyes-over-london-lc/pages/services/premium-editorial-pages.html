What does “fallback” mean here?

Every editorial link on this page is a smart link:
Primary: https://13thsole.netlify.app/pages/blogs/editorials.html/billions_stolen_from_american_workers
Fallback: https://13thsole.netlify.app/pages/blogs/editorials.html/billions_stolen_fom_american_workers
If the primary route doesn’t return the correct page, the link automatically routes to the fallback.

How does it detect failure?

It fetches the primary page first. If it fails (network/404) or returns an unexpected page body, it switches the link to the fallback and navigates there.
