Hardening

Before hostile networks

  • Change the live password.
  • Use SSH keys, not passwords.
  • Keep Ollama bound to localhost.
  • Do not expose Open WebUI without auth/reverse proxy.
  • Keep provider keys in /srv/sove-reign13/secrets.

Aegis Agent

Repo scan, plan, propose, apply

s13-agent-init /srv/sove-reign13/workspaces/my-repo
s13-agent-scan /srv/sove-reign13/workspaces/my-repo
s13-agent-plan /srv/sove-reign13/workspaces/my-repo "close the public landing/app split"
s13-agent-propose /srv/sove-reign13/workspaces/my-repo "fix broken routes and return a unified diff"
s13-agent-apply /srv/sove-reign13/workspaces/my-repo .s13/runs/propose-*/proposed.patch "./scripts/smoke.sh"

The agent writes every run under .s13/runs. It validates patches with git apply --check before editing.

Reliquary

Backup before risky work

s13-backup /srv/sove-reign13/workspaces/my-repo
s13-reliquary list /srv/sove-reign13/workspaces/my-repo/.s13/reliquary
s13-reliquary verify /path/to/archive.manifest.json

Archives include a manifest and SHA256 checksum. This is the rollback lane before autonomous edits.
