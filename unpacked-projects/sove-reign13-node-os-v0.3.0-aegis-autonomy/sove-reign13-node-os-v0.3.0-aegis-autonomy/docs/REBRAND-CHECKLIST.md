# Rebrand Checklist

Use this before publishing or handing the OS to anyone else.

## Required

- Product name is SoveReign13 Node OS.
- AI lane is Orynth 7.6.
- The system is described as NixOS-based, not as a brand-new OS kernel.
- Upstream NixOS license/copyright notices are not removed.
- Upstream logos are not used as SoveReign13 logos.
- Default live password is disclosed only in internal/operator docs.
- Public marketing does not claim completed integrations that are not proven.
- Model weights are described as post-install pulls, not bundled assets.

## Replaceable identity files

- `README.md`
- `BRAND.md`
- `flake.nix` brand object
- `nixos/modules/branding.nix`
- `prompts/orynth/ORYNTH_7_6_SYSTEM.md`
- `command-center/index.html`
- `command-center/styles.css`
- `assets/wallpapers/sove-reign13-wallpaper.svg`

## Suggested public claim

SoveReign13 Node OS is a branded NixOS-based developer and deployment operating-system profile designed for sovereign code operations, local AI workflows, artifact recovery, autonomous IDE hosting, and self-hosted platform administration.
