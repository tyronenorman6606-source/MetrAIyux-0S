# SoveReign13 Node OS Brand Pack

## Name

SoveReign13 Node OS

## Version

0.3.0 — Aegis Autonomy

## Positioning

A sovereign developer-node operating system profile for builders who need control over code, AI runtime, deployment tooling, recovery workflows, and infrastructure command surfaces without depending on a single hosted platform.

## Honest one-liner

A branded NixOS-based live ISO and workstation foundation for autonomous IDE hosting, local AI coding workflows, and deployment operations.

## Core product lanes

- Orynth 7.6: local-first AI brain and router layer.
- SceptR: build/deploy/release command engine.
- Veyra3.1: DNS/SSL/routing/origin mapping lane.
- Reliquary: backup, export, artifact, and rollback system.
- Aegis: hardening and security posture.
- Citadel: persistent node/workstation posture.
