Auth gate

Set TRUSTED_HEADER_AUTH=true only behind your real gate.
Gate must inject x-s13-gate-secret matching TRUSTED_HEADER_AUTH_SECRET.
Never expose direct trusted headers without the secret.

Billing

Set STRIPE_SECRET_KEY.
Set STRIPE_PRICE_STARTER/STUDIO/AGENCY.
Set STRIPE_WEBHOOK_SECRET and test checkout session completion.

Forge engine
