Source custody

Hosted for the client. Owned by the account that deployed it.

SkyeNet separates the public app from the source handoff. A client can receive a live hosted surface without receiving the source code. The authenticated account that deployed the bundle can download it, store it in SkyeDrive or SkyeVault, create an instant gated handoff, or generate an encrypted secure .skye source pack.

Cross-account client source handoff is a deliberate transfer event, not an accidental console leak.
