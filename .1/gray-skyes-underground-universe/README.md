# Gray Skyes Underground Universe

Static artist universe built from the dropped Gray Skyes intake assets.

## Pages

- `index.html` - main artist hub with base64 scene, video preview, editable song wall, gallery, posts, and 0S founder lane.
- `music-video.html` - dedicated loop room for `Chicago's Underground Trap Metal King`.
- `dashboard.html` - artist title editor. It saves display names into browser storage under `gray-skyes-track-names-v1`; the hub reads those titles live from the same browser origin.
- `scenes/gray-base64-scene.html` - standalone base64-embedded visual scene using Gray's cutout and photo assets.

## Media

- `media/audio/` contains 14 canonical songs.
- `media/video/` contains the full Chicago video and the second ambient clip.
- `media/images/` contains the cutout, photos, and 0S mark.

Duplicate handling is recorded in `receipts/ASSET_RECEIPT.json`.
