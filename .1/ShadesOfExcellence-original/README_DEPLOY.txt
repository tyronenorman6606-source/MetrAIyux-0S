Deploy options:
1. Netlify drag-and-drop: drop this unzipped folder or the zip contents into Netlify Deploys.
2. cPanel/shared hosting: upload all files exactly as-is so index.html stays at the web root.
3. Any static host: publish this folder as the site root.
