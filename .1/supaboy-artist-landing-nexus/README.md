# SupaBoy Artist Landing Nexus

This folder is isolated from the live SkyeMusicNexus surfaces.

Contents:

- `index.html` - SkyeMusicNexus SupaBoy artist hub with the sharp text, drag rail, internal SUPABOY music link, and chrome treatment folded into the main landing page.
- `artist-id-upload.html` - working browser-local proof for artist ID, release ID, track ID, audio upload, media upload, artist page population, playback, and manifest export.
- `artist-upload-proof.js` - IndexedDB media persistence and playback logic.
- `nexus.css` - standalone Nexus-style visual system for this proof folder.
- `nexus.js` - Music Nexus scroll progress, pointer aura, drag rail, and hub anchor behavior.
- `assets/skye-music-nexus-logo.png` - approved SkyeMusicNexus logo used across this Nexus surface.
- `SUPABOY/` - static SupaBoy artist landing artifact rebuilt from `.1/supaboy-merser31/dist`.

Boundary:

This proof demonstrates browser-local ID binding and media playback. It does not claim live DSP delivery, royalty settlement, formal legal clearance, registered DMCA operations, or production object storage. Those lanes need separate provider deployment and proof.
