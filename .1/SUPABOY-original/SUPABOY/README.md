# SupaBoy Netlify Drop Package

This is a static Netlify-ready multi-surface artist website.

## Deploy
Drag this folder or ZIP into Netlify, or connect it to a repo. No build command is required.

## Included
- `index.html` main artist world / conversion hub
- `story.html` Nigerian roots + Chicago grind story surface
- `music.html` SLB project, tracklist, and 24 Hr In Houston proof surface
- `live.html` Twitch, shouts, media, and Netlify shout request form
- `booking.html` press kit, booking lane, and Netlify booking form
- `thanks.html` form success page
- `404.html` custom not-found page
- `netlify.toml` publish and header config
- `_redirects` clean path support
- `robots.txt`
- `favicon.svg`
- `assets/` optimized WebP visual surfaces

## Netlify Forms
The booking and shout request forms are wired with `data-netlify="true"`, form names, hidden `form-name` fields, honeypot spam fields, and `/thanks.html` success routing. After deployment, submit one test entry for each form so Netlify activates them in the Forms tab.

## Asset approach
Images are used as campaign surfaces, release proof, story cards, press images, and live/fan moments. This is not a gallery dump.
