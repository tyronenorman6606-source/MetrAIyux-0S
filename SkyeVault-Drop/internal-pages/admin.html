Setup guide

Use the repo-side command when a project workspace needs to be stored as one receipt-backed archive. It builds a sanitized zip, excludes secrets and generated junk, uploads through this vault, then writes a local receipt JSON.

1. Prove the package locally npm run vault:dry-run
2. Upload and create a receipt npm run vault:push
3. Track the proof .skyevault-out/skyevault-receipt-*.json

The command excludes .env files, .git, node_modules, Netlify/Wrangler folders, backups, database dumps, WAL archives, private keys, old archive bundles, and files flagged by the built-in credential scan.
