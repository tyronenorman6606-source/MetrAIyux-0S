What this page can and cannot do

This protected operator page can walk you through every value, generate safe tokens, generate the bootstrap JSON, configure alerts, and check the deployed environment after you add the Netlify variables. It cannot create Cloudflare R2 keys for you from the browser, and it never stores secrets anywhere except your own clipboard/page session when you paste them.

Deployment checklist

Baby steps

Do this in order

01

Confirm your Cloudflare account

Open Cloudflare, confirm the account that owns the R2 bucket for this vault.

02

Create an R2 access key

Create an R2 access key, then create a JSON key. Copy the service account email and keep the private key safe. Do not commit it to GitHub.

03

Choose R2 prefixes

Use private R2 prefixes for config, primary intake, overflow/fallback intake, and backups.

04

Deploy through Git on Netlify

Push this package to GitHub, import the repo in Netlify, and deploy it as a normal Git-based Netlify site so Functions and npm dependencies build correctly.

05

Add environment variables

Use the generator below. Paste the values into Netlify Site configuration → Environment variables. Keep R2 secrets private.

06

Redeploy, test, then send the upload link

Trigger a deploy after adding env vars. Open this page on the live site, run diagnostics, then upload a small proof file before sending the client portal URL.

Repo snapshot command

            
Let an operator push a whole workspace into the vault safely

          

        

        
Add the repo-side helper to any project that needs controlled vault snapshots. The helper packages a sanitized zip locally, scans staged text files for common secret patterns, uploads through this vault's R2 multipart API, and writes a receipt JSON.

        

          

            Required local values
            SKYEVAULT_DROP_URL
            CLIENT_PORTAL_KEY
          

          

            Test without upload
            npm run vault:dry-run
          

          

            Upload with proof
            npm run vault:push
          

        

        
If your deployed vault uses a custom allowed origin, set SKYEVAULT_UPLOAD_ORIGIN locally before running the push command.
