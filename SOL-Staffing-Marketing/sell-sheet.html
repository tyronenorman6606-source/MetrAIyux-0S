Objection Handling

The hard questions, answered straight.

"Is this a real staffing platform or just a static website?"
It started as a static staffing website and now includes a live backend layer: Skyegate-authenticated internal routes, server-side records, secure uploads, an admin dashboard, and a live brain function. It is not a full payroll/EOR/insurance system. It is a real front-end/business OS and intake platform.
"Can we use it for sensitive documents immediately?"
Technically, the authenticated upload function exists. Operationally, do not collect I-9, tax, medical, background-check, payroll, or other regulated documents until retention, access, legal, and compliance procedures are approved.
"Does the brain actually use AI?"
The browser brain is local JavaScript plus JSON. The server brain is wired to call Ollama or an OpenAI-compatible GPU/vLLM endpoint once env vars are configured. The system is honest about both modes.
"What must be configured before production?"
Skyegate FS27 introspection URL, admin roles, storage policy, business/legal replacements, real phone/address/legal entity, verified government claims if used, and optional model endpoint variables.
