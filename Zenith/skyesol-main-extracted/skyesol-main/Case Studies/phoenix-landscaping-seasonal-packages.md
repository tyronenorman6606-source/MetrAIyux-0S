Overview

Phoenix Landscaping: Seasonal Packages + Lead Qualification

Seasonal tiered packages and install/maintenance separation to reduce scope confusion and improve lead quality.

🏷️

### Client Snapshot

Landscaping crew handling maintenance and installs.

🧩

### The Challenge

Price-shopping leads without scope clarity caused time drain and misaligned expectations.

🧠

### Core Outcome

Seasonal tiered packages and install/maintenance separation to reduce scope confusion and improve lead quality.

Execution

Solution & Build Details

A structured delivery—built for clarity, speed, and operational control.

⚙️

### What We Did
- Structured services into seasonal packages with clear boundaries.
- Separated maintenance requests from install requests.
- Added install intake to capture constraints like HOA rules and photos.

🧱

### What We Built
- Package tiers with scope boundaries
- Install request intake (photos, measurements, HOA constraints)
- Service area and scheduling expectations
