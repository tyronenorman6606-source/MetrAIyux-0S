# Logo Standards

Agents must treat logos as identity assets, not as generic UI decoration.

## First Rule

Use existing logo assets before generating or drawing a new mark.

Approved logo examples in this workspace are finished visual systems: transparent PNG/WebP/SVG assets, dimensional gold/blue or gold/purple styling, glow, emblem logic, and intentional wordmark pairing. They are not rounded-square initial badges.

## Required Workflow

1. Call `design_logo_manifest`.
2. Check whether the product or parent brand already has a logo, emblem, mark, or poster asset.
3. Use the existing transparent mark in navigation, favicon/app surfaces, and hero proof areas when relevant.
4. If the exact product has no logo, use a clean wordmark first and avoid inventing a fake badge.
5. Run `design_logo_audit` before browser QA.
6. Review the browser screenshot at desktop and mobile sizes.

## Reject

- Rounded-square initial tiles like `SOL`, `AI`, `OS`, or `SKY` inside a gradient box.
- Text-only `brand-mark` spans pretending to be logos.
- Random shields, cubes, stars, circuit icons, or spark marks that do not come from the brand system.
- Logo containers with heavy border radius when the real asset is transparent/floating.
- Tiny nav-only brand marks when the brand/product should be a first-viewport signal.
- Replacing a finished existing logo with a generated CSS badge.

## New Sub-Brands

When a new sub-brand has no asset yet:

- Prefer a strong wordmark using the page typography and the parent brand palette.
- Use the parent logo as a small endorsement if appropriate.
- Do not create a permanent-looking emblem unless the user asks for logo design.
- If asked to design a logo, produce multiple identity directions and compare them against the existing logo assets before selecting one.

## Visual Direction

The workspace logo language leans toward:

- Transparent/floating marks.
- Gold plus electric blue or gold plus purple.
- Dimensional metallic highlights.
- Emblem geometry, arcs, rings, wings, deity/founder authority, or protected-OS symbolism when relevant.
- High-detail poster assets only where there is enough space to breathe.

Use that as taste guidance, not a command to make every logo identical.
