SkyeGateFS27 auth lane

Generated Gate ID. Human PIN. Real recovery codes.

This lane lets an already-authenticated user create a short numeric Gate ID plus PIN credential. FS27 stores only hashed PIN material and hashed recovery codes. Recovery delivery uses the configured email webhook; local/dev mode returns preview codes once so the flow can be tested honestly.

Back to FS27 Gate map HouseOperations

Create PIN gate

Paste a current SkyeGate session token, choose a 4-12 digit PIN, and FS27 issues the generated Gate ID plus one-time recovery codes.

PIN login

Enter the generated Gate ID and PIN, or paste the combined digits as one credential.

Recovery login

Recovery codes are one-time use. After this works, rotate the PIN or issue a fresh recovery set.

Rotate recovery codes

Paste a current SkyeGate session token and either a Gate ID or credential ID. FS27 invalidates the old code set and sends a fresh one-time batch.

Result

Waiting for a gate action.
