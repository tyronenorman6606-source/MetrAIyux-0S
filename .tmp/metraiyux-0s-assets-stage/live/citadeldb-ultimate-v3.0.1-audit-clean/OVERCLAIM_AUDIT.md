# CitadelDB Overclaim Audit

This file exists because prior packages added too much scaffold language.

## Truth

CitadelDB has serious platform structure.

CitadelDB does **not** yet have complete hosted-platform parity.

## Real / implemented foundation

✅ dashboard surfaces exist  
✅ app database provisioning foundation exists  
✅ project/self-service schema exists  
✅ SQL console endpoint exists  
✅ query history exists  
✅ table preview foundation exists  
✅ teams/plans/quotas schema exists  
✅ billing/subscription schema exists  
✅ entitlement check endpoint exists  
✅ branch request schema exists  
✅ proof/receipt culture exists  

## Scaffold / not closed

☐ public customer auth is not live  
☐ Stripe checkout is not live  
☐ Stripe webhook has not been live-tested  
☐ subscription blocking is not proven across all paid routes  
☐ database branching is not live-proven  
☐ table browser is preview-only, not full editor  
☐ usage metering is event-based scaffold, not billing-grade compute/storage metering  
☐ HA/PITR is not live-proven  
☐ real customer migration receipts do not exist in this package  

## Banned public claim

Do not say:

```text
CitadelDB is ahead of incumbent hosted database platforms.
```

Allowed:

```text
CitadelDB is a sovereign database platform foundation with self-service provisioning, SQL console, lifecycle workflows, commercial scaffolding, and proof-led operations.
```
