System path

Knowledge moves through the same 0S architecture, not a side password or loose app lane.

1. GateAdmin and SaaS calls require the shared FS27/SkyGate/Free99 session headers and cookies.
2. ScopePlatform memory is owner/admin only. Tenant memory is limited to the matching workspace and client identifiers.
3. StoreLarge knowledge bodies write to Cloudflare R2. Metadata, counts, and search indexes live in KV.
4. CiteContext packs include item IDs, source kinds, hashes, and snippets so answers stay traceable.
5. MirrorAudit mirroring is best effort and cannot break the primary R2/KV write path under load.
