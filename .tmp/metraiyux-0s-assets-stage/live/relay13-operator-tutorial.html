Operator tutorial

Run the inbox like a room, not a pile of random messages.

The operator flow is short: authenticate, pick workspace, open thread, reply or route, then mark the state.

First five minutes

Do these in order.

1. Load Platform

Sign into 0S/SkyGate, load workspaces, and select the company lane.

2. Read Thread

Open the conversation list, inspect source URL, route metadata, customer name, and message history.

3. Choose Route

Reply directly, leave it pending for the owner, or turn it into a ConnectLog follow-up/opportunity.

4. Close Loop

Send the operator reply, update status, assign owner, and keep proof attached to the workspace.

Admin mental model

Relay13 is the live conversation room. ConnectLog is the memory room.

When a message needs action later, it should become a ConnectLog card, request, event, or follow-up. When it only needs a reply, handle it in Relay13 and mark the thread.

Keep private things private

Private gate credentials stay out of public page code. The customer widget can send messages without seeing owner secrets.
