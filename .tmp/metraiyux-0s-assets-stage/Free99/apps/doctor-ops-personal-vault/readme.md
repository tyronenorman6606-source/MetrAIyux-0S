# Doctor Ops Personal Vault v6.0

A local-first personal workflow companion for doctors. This is intentionally scoped as a small, useful utility that could support a low monthly price point because it is not pretending to be a full EHR, billing platform, or enterprise compliance suite.

## Product promise

Doctor Ops Personal Vault gives a doctor one private workspace for practical office work: intake tracking, SOAP note support, referrals, prior auth, labs, medication reconciliation, imaging follow-up, care gaps, visit prep, consents, chronic care, discharge packets, and incident handoffs.

The core value is confidence: local data, clear exports, receipts, version history, and backups.


## V6 website + logo launcher upgrade

Version 6.0 adds a proper public website at `index.html`, moves the private command deck to `app.html`, wires in the official logo, separates the full advertising graphic, adds app icon assets, adds a web manifest that launches installed sessions directly into the app, and adds Netlify static routing. These upgrades do not add external storage or telemetry.

## Local data posture

- Browser-only mode stores workspace data in the user browser with export/import JSON.
- Optional local runtime mode stores data in `data/platform-store.json`.
- Runtime backups are written to `data/backups/`.
- No external database is configured.
- No telemetry is configured.
- No third-party cloud sync is configured.
- Auth is intentionally not implemented; upstream auth can pass context into the app.

Important: this package does not claim HIPAA certification, medical advice, billing advice, legal advice, or EHR replacement status. The operator is responsible for their own legal/compliance environment.

## Main files

- `index.html` — public website / sales launcher
- `app.html` — command dashboard and local confidence vault
- `apps/` — 13 workflow apps
- `assets/js/core.js` — shared workflow engine
- `assets/js/platform.js` — cross-app command deck, workspace import/export, vault UI
- `assets/js/api-client.js` — optional same-origin API bridge
- `server/doctor-ops-server.mjs` — local Node HTTP runtime
- `server/storage-adapters.mjs` — JSON file store and backup manager
- `data/platform-store.json` — local runtime store generated at first run
- `data/backups/` — local backup files generated by runtime
- `docs/LOCAL_PRIVACY_AND_BACKUP_GUIDE.md` — operator privacy/backup guide
- `docs/SALEABLE_PRODUCT_POSITIONING.md` — $2.99/month positioning
- `docs/V4_LOCAL_VAULT_CLOSURE_REPORT.md` — local vault closure report
- `docs/V5_VISUAL_OVERHAUL_REPORT.md` — major visual overhaul report
- `docs/V6_WEBSITE_LOGO_LAUNCHER_REPORT.md` — public website and logo wiring report
- `assets/brand/` — official logo, advertising graphic, and app icon assets
- `manifest.webmanifest` — app install/start URL metadata
- `_redirects` and `netlify.toml` — Netlify drop routing and static headers

## Honest product boundary

Worth selling at a low personal-use subscription if positioned correctly: a practical local clinical workflow companion. Not worth selling as a full clinical platform, EHR, claims system, or compliance-certified cloud product yet.
