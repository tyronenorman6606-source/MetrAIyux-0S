# UPGRADE NOTES — v1.4.0

## Build identity

SkyeArcade: Sovereign Vault v1.4.0 continues the ten-game static browser anthology with a persistent Vault Armory progression layer.

## Added

- Vault Armory panel.
- Five persistent buyable Vault Relics.
- Coin-gated relic purchases.
- Relic ownership stored in localStorage.
- Relic export/import migration.
- Vault Relics profile stat.
- First Relic Forged achievement.
- Armory Complete achievement.
- Tenfold Mastery achievement.
- Pressure Gauntlet Crown achievement.
- v1.4 service worker cache key.

## Mechanical relic effects

- Ace Mantle modifies SkyeAce HP, Focus Draw, and spade damage.
- Origin Aegis modifies Uptime War energy, core HP, and overclock cost.
- Veyra Compass modifies DNS Dominion move count and trace cost.
- Reliquary Beacon modifies Reliquary HP and scanner charges.
- Operator Momentum modifies win payouts and selected strategy-game starts.

## Auth stance

No auth added. No backend requirement added. No account table added. This remains a local-first static deploy.
