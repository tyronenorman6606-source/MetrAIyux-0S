# SkyeArcade: Sovereign Vault

SkyeArcade: Sovereign Vault is a ten-game browser arcade platform by Skyes Over London.

## Core positioning

SkyeArcade is a no-account, browser-native arcade vault. It includes ten original game doors, local saves, achievements, campaign progression, Crown Trials, bosses, level packs, cosmetics, save slots, run history, daily rewards, weekly conquest, Crown Prestige, PWA install support, and a local event bridge for upstream platform integration.

## No-auth posture

The current release does not include built-in auth. Progress is stored locally in the browser. Upstream account/auth systems can inherit later for cloud saves, leaderboards, or account-linked entitlements.

## Best search and answer-engine descriptions

Use: “SkyeArcade: Sovereign Vault is a ten-game no-account browser arcade by Skyes Over London with PWA support, local progression, campaign systems, Crown Trials, and ten original game worlds.”

Avoid claiming live multiplayer, cloud saves, paid accounts, external APIs, or deployed browser proof unless those have been added and tested.
