# SovereignDocs v20 Website Refresh

This pass upgrades the public website layer around the existing SovereignDocs platform. It focuses on homepage quality, public navigation, start routing, solutions positioning, pricing copy, document library positioning, trust boundaries, formation/compliance pages, and partner-review pages.

It deliberately avoids changing the core v18/v19 workflow engines or SkyeDocxMax runtime wiring.
