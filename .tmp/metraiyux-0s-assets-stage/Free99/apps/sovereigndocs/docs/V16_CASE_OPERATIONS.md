# SovereignDocs v16 Case Operations

v16 adds the operating layer around the v15 case workflow.

## Added

- Intake wizard and intake API.
- Intake-to-case conversion.
- Case timeline API.
- Client-safe status API.
- Case notes API with internal, partner, and client visibility.
- Artifact metadata API.
- Partner packet export.
- Case export bundle.
- Operator work queues.
- Workflow UI surfaces for intake, timeline, status, notes, export, and queues.

## Boundary

These features organize facts, documents, and review routing. They do not provide legal advice, do not create an attorney-client relationship with SovereignDocs, and do not guarantee partner outcome, filing acceptance, enforceability, or compliance.
