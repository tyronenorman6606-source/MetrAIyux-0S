No-overclaim boundary

This receipt proves local browser workflows, not managed custody.

SkyeBox is an encrypted local PWA. It does not sync secrets to a server, recover a lost vault password, replace enterprise credential policy, or prove a deployed managed authenticator service. HouseOperations is a static local-state command app; SkyePay/FS27 owns paid checkout, owner approval, plan policy, and activation. Cloud persistence still requires a separate Worker/D1/KV persistence scope.
