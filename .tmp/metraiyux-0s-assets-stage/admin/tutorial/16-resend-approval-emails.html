Lesson 16

Wire Resend approval emails.

This lesson turns approval gates into real admin notifications.

Steps

  1. Create or open your Resend account.
  2. Verify your sending domain.
  3. Create a Resend API key.
  4. Set the key with npx wrangler secret put RESEND_API_KEY.
  5. Set RESEND_FROM_EMAIL, ADMIN_APPROVAL_EMAIL, and PUBLIC_ADMIN_URL in wrangler.toml.
  6. Deploy the Worker.
  7. Run the approval email test endpoint.
  8. Send a command such as “draft and publish 5 LinkedIn posts” from the Main Brain Chat. The system should route, block publishing, and email you for approval.

Pass condition

You receive an approval email, the email links back to the Admin Approval Inbox, and the Worker ledger records the email attempt.
