Current Valuation and Deployed Valuation

The platform now has a live public overview asset and a named Merser developer-access lane, so valuation should treat it as deployed product infrastructure and public sales collateral, not only a packaged ZIP.

Operator valuation bands

  • Current deployed asset: $2.05M-$2.55M directional replacement-cost/productized-asset band after Merser, remote MCP, Skyes platform lanes, and live proof accounting.
  • Deployed operating platform with public overview, full system route, D1, auth, Resend, isolation, source-world MCP access, and stress/browser receipts: $1.55M-$2.05M section accumulation before commercialization premium.
  • Revenue-backed SaaS with customer workspaces: $750K-$3.5M+ depending on MRR, churn, retention, connector depth, and usage proof.

What changed

The public spectacle overview is live, and Merser now adds a named Skyes Over London developer-access lane with npm/npx, stdio, local HTTP, gate-owned remote MCP, PWA/logo surface, repeatable stress proof, and a reported $6K client-access interest. Directional valuation only. Live production value depends on deployed proof, customer usage, retained revenue, protected secrets, connector policy, and verified approval controls.
