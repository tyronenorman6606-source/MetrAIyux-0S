Honest capability disclosure

The default mode is not a hidden ChatGPT clone. It is a local retrieval brain packaged with this site. It gives deterministic, grounded answers from the included knowledge base. If apps/brain-service is enabled and LOCAL_LLM_PROVIDER=ollama or LOCAL_LLM_PROVIDER=openai, it can call the configured model provider.

Configuration

Optional model variables

LOCAL_BRAIN_ENABLED=true
BRAIN_SERVICE_PORT=8099
LOCAL_LLM_PROVIDER=openai
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4o-mini

LOCAL_LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://host.docker.internal:11434
OLLAMA_MODEL=qwen2.5-coder:7b-instruct

Use OpenAI for production-hosted model answers or a stronger coding/ops model on your GPU later. The page remains useful even when the model is offline.

Where it lives

The brain is inside the site, not a separate product promise.

It ships as brain.html, assets/brain.js, a JSON knowledge base, an optional Node brain-service, env examples, and proof docs. That makes the platform easier to demo, sell, deploy, and operate without needing you to remember every runbook.
