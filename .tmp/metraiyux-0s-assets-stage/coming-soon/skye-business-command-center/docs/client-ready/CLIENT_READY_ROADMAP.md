# Client-Ready Roadmap

This package is sellable as a deployment, configuration, hosting, training, and support offer. It must not be sold as a proprietary replacement for every underlying open-source application.

## Sell today
- Dedicated instance deployment.
- CRM pipeline setup.
- Support inbox/ticketing setup.
- Intake/quote forms.
- Estimate/invoice system.
- Branded operator hub.
- Setup walkthrough and monthly maintenance.

## Do not sell today
- Banking, payment-gateway, PayFac, tax, legal, compliance-certification, HIPAA, SOC 2, or regulated industry guarantees.
- Multi-tenant isolation without dedicated instances.
- Proprietary ownership of upstream AGPL/GPL software.

## Phase 2 upgrades
- SSO/upstream auth adapter.
- Central metrics panel.
- S3/R2 attachment gateway.
- n8n/automation bridge.
- Client-specific theme generator.
- Automated installer completion where upstream apps support CLI/API setup.
